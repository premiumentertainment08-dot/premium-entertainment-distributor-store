PREMIUM ENTERTAINMENT STORE - GITHUB PAGES

UPLOAD:
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
3. Make sure index.html is directly in the repository root (not inside another folder).
4. Upload all folders/files that came with index.html, especially assets.
5. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root) > Save.

IMPORTANT:
Do NOT upload the ZIP itself as the website.
The repository root must contain index.html.
