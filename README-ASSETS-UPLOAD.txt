UPLOAD STRUCTURE
----------------
Upload ALL files from this package to the GitHub repository ROOT.

IMPORTANT:
- index.html must be directly in the repository root.
- The entire assets folder must also be directly in the repository root.
- Do NOT upload the outer folder itself.
- Keep assets/ as a folder and upload everything inside it.

Example:
repo/
  index.html
  assets/
    (all image/logo files)
  music.mp3
  admin.html
  announcements.js
  firebase-config.js
  ...
